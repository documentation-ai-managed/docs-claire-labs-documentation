## Essay Grading

Our AI-powered essay grading tool evaluates written assignments based on customizable rubrics.

<Steps>
  <Step title="Upload Assignment" icon="upload">
    Submit student essays through our API or dashboard.
  </Step>
  <Step title="Configure Rubric" icon="settings">
    Define grading criteria and weightings.
  </Step>
  <Step title="Run Assessment" icon="play">
    Let AI analyze the content and provide scores.
  </Step>
  <Step title="Review Results" icon="eye">
    Examine detailed feedback and scoring breakdown.
  </Step>
</Steps>

<Tabs>
  <Tab title="API Usage" icon="code">
    ```javascript
const result = await claireLabs.assessEssay({
  content: essayText,
  rubric: {
    criteria: [
      { name: 'Content', weight: 0.4 },
      { name: 'Grammar', weight: 0.3 },
      { name: 'Structure', weight: 0.3 }
    ]
  }
});

console.log(`Score: ${result.score}/100`);
console.log(`Feedback: ${result.feedback}`);
    ```
  </Tab>
  <Tab title="Dashboard" icon="layout-dashboard">
    Use our web interface to upload essays and view results in real-time.
  </Tab>
</Tabs>

<Callout kind="tip">For best results, provide clear rubric criteria and sample essays for AI training.</Callout>

## Feedback Generation

Generate personalized, constructive feedback for students based on their work.

<Expandable title="Feedback Types" default-open="false">
  - **Strengths**: Positive reinforcement of good work
  - **Areas for Improvement**: Specific suggestions for growth
  - **Next Steps**: Actionable recommendations
  - **Resources**: Links to helpful learning materials
</Expandable>

<CodeGroup tabs="Python,JavaScript">
  ```python
feedback_request = {
    "student_work": "Essay content here...",
    "assignment_type": "literature_analysis",
    "student_level": "high_school",
    "focus_areas": ["thesis", "evidence", "analysis"]
}

response = client.generate_feedback(feedback_request)
print(response["feedback"])
print(response["score_breakdown"])
  ```
  ```javascript
const feedback = await claireLabs.generateFeedback({
  studentWork: 'Essay content here...',
  assignmentType: 'literature_analysis',
  studentLevel: 'high_school',
  focusAreas: ['thesis', 'evidence', 'analysis']
});

console.log(feedback.feedback);
console.log(feedback.scoreBreakdown);
  ```
</CodeGroup>

## Best Practices

Maximize the effectiveness of our assessment tools with these guidelines.

- **Calibrate AI Scoring**: Regularly review and adjust AI-generated scores
- **Provide Context**: Include assignment instructions and learning objectives
- **Combine AI with Human Judgment**: Use AI as a supplement to teacher expertise
- **Student Privacy**: Ensure compliance with data protection regulations
